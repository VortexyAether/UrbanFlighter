# Urban Flighter Frontend

React 19 + TypeScript + Vite cockpit for the Urban Flighter simulator.

See the [repository README](../README.md) for the full project overview, modes, controls, LiDAR/rolling sensor-map scope, and backend startup instructions.

## Commands

```bash
npm install
npm run dev
npm run smoke:lidar
npm run build
```

The frontend runs at `http://127.0.0.1:5173` by default.
